# 字段、清洗和质量门

## 字段归属

| 文件 | 字段与用途 |
| --- | --- |
| `knowledge_base.jsonl` | 每行仅 `id,title,chapter_id,chapter_order,content`。`content` 包含本版正文和内部结构，保留原段落空行；不塞入页码、清洗解释、OCR 置信度或整页注释。 |
| `正文段落.jsonl` | 独立段落事实层：`paragraph_id,section_id,chapter_title,kind,text,pdf_pages,source_lines`。跨页段落保持为一个段落，ID 绑定源身份、章节与行集合。 |
| `archive/页下注释.jsonl` | 移出的页下注，保留原文本、源页、行索引和区域依据。 |
| `archive/非正文材料.jsonl` | 其他不入正文的材料，保留来源与角色决定；不能仅因不认识而删页。 |
| `audit/cleaning-ledger.jsonl` | 原文片段、修改后片段、编辑类型、原因、源图摘要和位置。清洗必须可追溯。 |
| `pages/` | 原始 OCR 页记录，保留几何和真实模型身份；源级清洗不覆盖该层。 |
| `knowledge_base.meta.jsonl` | 作者、语言、书籍路由和源路径等元数据；覆盖规范语料全部 ID。 |
| `knowledge_base.rag.json`、`knowledge_base.vectors.jsonl` | 摘要绑定的检索清单与向量，模型及维度需匹配。正文变化后重建索引。 |
| `audit/` | 源审阅、重建检查、Word 往返一致性、实际渲染、版面审阅及注册回执。 |

规范五字段语料由项目发布器生成。来源与处理细节写旁车；不得为实现检索功能向规范语料加列。
每段文本与一个检索块完整匹配，才能声称没有段内切块；将所有块拼接后匹配不足以证明这一点。

## 清洗边界

| 问题 | 正确动作 | 需要保留的依据 |
| --- | --- | --- |
| 软换行混成段落 | 依据缩进、行距与源列边界合并；跨页接续不靠句号猜测 | PDF 页集合、原行索引 |
| 同行左右文字倒置 | 分组后按 x 顺序合并，保留所有碎片 | 原框与顺序 |
| 大段页下注混入正文 | 核验分隔线与区域后移出，按页另存 | 原图、分隔位置、注释文本 |
| 编者材料或书末装置挤占正文 | 按用户版本目标分类，保留档案 | 角色、页集合、选择原因 |
| 真正文被判空白 | 看源图区分正文、真正空白与反面透印 | 明确分类和图像证据 |
| 重复章首 | 只处理审阅计划中的开头标题别名；真正内部同名小标题保留 | 原标题与位置 |
| 日期或编号被清掉 | 保留 `[1933]`、`[1963年版补注]`、正文 `(1)` 等；只有确认的注号才移出 | 精确编辑与理由 |
| `[]`、孤立括号、未知字形 | 定位原图，确认是否注号误识或正文损坏，按明确记录修复 | 原词、校订词、原图摘要 |
| 省略号出现 | 对照原文判断；访谈中的原省略号要保留 | 源段与输出段 |
| 外文字形或人名失真 | 看图转录；不以熟悉的术语猜缺字 | 定点校订范围 |

自动检测可以提出候选，不产生“已看图”结论。不能用全局删除方括号、删长段、删低分行或清空未知字形
替代真实核验。图示、作者补论和访谈是有结构的正文，不因为含数字、外文或说明性语言就移出。

## 分层质量门

| 门 | 阻塞条件 | 能证明什么 |
| --- | --- | --- |
| 来源与 OCR | PDF 摘要改变、页缺失/重复、缺坐标、读取错方向、旧来源缓存冒充本次结果 | 此重建有对应源及几何记录 |
| 计划与审阅 | 页面没有去向、逻辑顺序重复、排除或校订没有证据、源审阅摘要过期 | 材料选择与页面顺序有审计依据 |
| 行覆盖与清洗 | OCR 行未分类或被消费两次、修改片段不匹配、被排除正文无法解释 | 每行的保留/移动/修改可追溯 |
| 文本完整性 | 未解决占位符、损坏字符、模型前言、校订无依据增加省略号、未处理的外文正文 | 已覆盖这些已知缺陷，不等于语义全真 |
| 结构与字段 | 字段增减、章节归属错、段落在块内被硬切、正文仍混脚注定义 | 规范语料和段落边界可用于检索 |
| 中文语言 | 实际待处理的非中文正文块 | 中文入库要求满足；原书专名/引文需正确判读 |
| 发布往返 | Word 缺字、多字、标题不同、段内异常硬换行或痕迹残留 | Word 与本版源稿一致 |
| 实际版面 | 渲染失败、空白/截断/重叠/乱码、重复标题、虚假的视觉审阅 | 已查看范围的真实显示可读 |
| 注册有效期 | corpus/Word/段落/计划/审阅变动、索引摘要/模型/维度失配 | 当前版本的注册和检索侧车有效 |

源稿往返、机器渲染、版面审阅及 OCR 原书精度的结论分别报告。缩略图可检查全书布局，不能证明每个小字正确；
有限抽查与定点校订不等于全书逐字人工审定。原始材料、旧版与移出内容保留，避免“少注释”变成不可逆删文。
