# 段落管线与诊断

适用于当前 translation-agent 扫描 PDF→中文入口；不要给电子 PDF、EPUB 或纯文本另造同一套 OCR。

流程：按页图像缓存 → 常驻 GPU Paddle → 完整原文/坐标 → 几何正文准备 → 硬失败及已校准低置信触发门 →
疑难页 Xiaomi 批量复识一次；结构异常直接人工核图 → CER/独立标点差异核图 → DeepSeek Flash 页内完整段落翻译 →
中文与标点门 → 中文知识库/Word/EPUB → 机器全页、人类异常与抽样、语义及实际渲染验收。

## 跨页边界

常规 `translate_non_chinese_pages` 按 PDF 页分别提交译文；邻页文本只作为上下文，不会把跨页句子合并为一个页级翻译单元。`reader_page_groups` 可以生成保留来源页和源摘要的阅读稿修复，但 `require_translation=True` 会拒绝该模式，因此它不是正式页级译文检查点。交付报告必须如实说明这一限制；若要把组稿纳入正式发布，需要单独实现并验证 group-aware 的源绑定、页覆盖与回写契约。

## 仓库实现

- `ingestion/scan_layout.py`：原文不改写，凭竖排框分离边栏/页码，列软换行不等于作者段落。无可靠几何不猜列序。
- `ingestion/ocr_quality_gate.py`：跨页结构检查和模型差异。引号两端一起漏掉时平衡检查无法发现。
- `tools/local_paddleocr_import.py`：GPU OCR 与一次复识；保存两套候选而非拼接。
- `tools/ocr_review.py`：人类决定绑定原图与原文 SHA；校订放旁层。
- `translation/paragraph_translation.py` / `book_pipeline.ChatTranslator`：整段自然正文，前后上下文各最多 800 字。
  prompt 对日语译中文要求所有标点逐字保留，并约束书名『』不可改《》、对话「」不可改弯引号、跨页不补闭合、不译入上下文。
  首次加一次完整重译，拒绝失败结果，不机械移动标点。
- 页缓存分开绑定真实模型、原文、版面/最多三邻页上下文及物理页边界；发布器独立复算。
- `audit/performance/translation-requests.jsonl` 和 `translation-run-summary.json`：包括失败请求和墙钟。

调用前检查实际接口与 prompt 版本；这些模块名不意味着插件的所有旧入口已自动支持新字段。

## 2026-10 江藤淳样本暴露的旧版问题

|原因|机制与证据|修正与限制|
|---|---|---|
|高置信 OCR 漏字形|PDF17 闭引号在检测框内却未识别；页平均约 0.97 仍有缺漏|不能只看置信；结构门、独立复识、核图。结构门不证明逐字正确|
|碎片翻译破坏语法|每个 Unicode 标点都切开，主句、修饰与引文关系失去上下文|整段翻译；局部翻译自然句读，严格保护源引文边界|
|标点验收形成循环|剥离译文标点，再回填已经漏标点的 OCR，签名相等也无法证明原图匹配|从图文原文层找缺漏；不在译文中机械“修复”|
|引号仍被默认中文排版替换|Flash 会把『』改《》、「」改弯引号，或译入上下文|显式书名/对话字形指令，上下文缩短且正文最后；校验失败阻断|
|递归重试很慢|片段 JSON 无效时递归二分，最坏约 2n−1 请求，HTTP 隐式重试又叠加|两次请求上限，日志包含失败轮次|
|GPU 冷启动|四页 Xiaomi 总 151.988 秒，生成仅 20.4 秒|可疑页共享引擎批次；不能把生成时间当整体耗时|
|源变化后复用旧译文|只绑定本页原文，没绑定坐标及邻页语境|独立输入 SHA；邻页校订/版面变更使缓存失效|
|结构通过被称作质量通过|中文、文件一致、引号数量不证明意义正确或无遗漏|人类语义复核与源图证据独立；报告仅承诺实际范围|

最终 PDF17—20 四页诊断为四请求、零重试、3.428 秒，只通过机器结构门；输入是代理建议原文，
不能作为人工真值或全书加速倍数。各诊断轮累计 32 请求、墙钟合计 48.846 秒，必须区分。
该书 179 页结构疑点只是保守信号，不是错误页真值；不要把个案页数、偏移或阈值用于别的书。

随后授权整本直接重译的结果：222 个非空页、16 workers、417 请求、77.426 秒；33 页通过结构门，
189 页未通过（181 页引文符号不一致、8 页外文残留）。这些结果不能全部归因于 OCR：缺损源文与模型
默认改排标点均可能造成差异。四页样本成功不能外推整本可发布。失败候选可单独导出阅读草稿，
不可写成已验收检查点；正式注册仍须通过源文和译文质量门。

后续用户发现阅读草稿含整段日文：PDF152 被拒绝的最后回复仍进入编译，是候选导出错误。
草稿也须通过语言完整性门；先检查语言再检查符号，避免重试只复制日文来满足符号约束。
短日文书名和断裂词尾不受长度阈值豁免，已译姓名后的短片假名发音注记可保留。
逐段检查实际 Word 和候选知识库，不能只检查 checkpoint 的成功页。

PDF134、196 原图证实页脚标题被拆成多个独立 glyph；仅查“重复书眉”会遗漏这些片段。
scan-layout-v2 以正文下缘和页码框实际纵向带分离页脚碎片；不与页码带重叠的附近图注保留，
不按字符串删除噪声。仍无法恢复的原文片段只能明确记录缺损，不能编造补齐或冒充已核图。
