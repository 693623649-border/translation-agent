# 从《私小説論》重做任务提取的故障模式

这些是排错线索，不是其他书的固定参数。376 页、53 个读者章节、55 个目录条目、纸页偏移 +3
只属于当时校验的那一个源文件；不可用于其他版本或其他书。原书专用目录留在仓库
`tools/books/shishosetsu_verified_toc.json`，只是实例。

| 现象 | 证据与原因 | 修复方向 |
| --- | --- | --- |
| 句子零碎、翻译用省略号补洞 | 竖列按横排 y/x 顺序拼接 | 检查源图与框坐标；重跑正确方向的 OCR，然后使旧译文失效 |
| 更改排序后“全部完成”但文字未变 | 旧缓存只保留行数；日志全是 skipped | 检查实际 processed 数和排序版本；无坐标旧记录不能可靠重排 |
| 目录篇数偏少，标题合并或失真 | 目录 OCR 和模型猜测被当作最终目录 | 逐条对照目录图与文章起始页，保留源题/译题双字段 |
| 后记、解说合为一篇 | 标题分隔页与真实正文起点不同 | 分类分隔页、空白页、解说；保持明确 PDF 页映射 |
| Word 封面出现下载站字样 | 用源文件 basename 当书名 | 从封面/版权页或用户给定信息明确 title/author |
| 译文记录“成功”但正文为空 | 响应未给有效 content，提交缺少非空检查 | 小样本验响应；检查 finish_reason；不提交空结果 |
| 大段引文未译却通过整页语言检查 | 假名占比或整页多数语言掩盖局部段落 | 对每段检查外文残留并定点修复 |
| 仅需修几个失败页却重译大片 | 把离散页号转成 min/max 范围；新模型使旧缓存不匹配 | 只合并相邻页；保留离散页组与真实模型身份 |
| 文本一致却 Word 很难阅读 | 字符门不检验视觉断行和标题布局 | 实际渲染并检查全书缩略图和风险页，回到源/发布器修复 |
| 单书已过门却全局同步失败 | 其他工作区含未译外文 | 报告无关阻塞；不能自动沿用旧库 allow-foreign 策略 |

原任务的校验没有证明每个旧字、人名与句子都经过人工逐字校订。后续交付应报告实际检查范围，
不要继承历史“全通过”话术。Docker、Word 和提供商的具体故障应按当次日志定位；不把关闭全局服务、
杀全部 Word 进程或改默认模型变成常规初始化步骤。
