# 阅读稿修复与替换

适用于竖排扫描书出现未译引文、孤立数字/单字、跨页断词，或用户要求以认可的新版替换旧产物。

## 有效处理顺序

1. 从截图独特句子定位章节、PDF 页和实际 Word 页，不假设两者页号相同。取当前源文本、模型回复、
   编译章节及源图，区分识别缺字、页边混入、译文失败和编译放入失败候选四类原因。
2. 先处理输入布局：`scan_layout.prepare_scan_pages` 按右起列序组正文，保存原始 OCR。
   页码框定位底部带，只有位于正文下缘之外、与页码框实际纵向带重叠的短框才分离为书眉/页脚。
   单字碎片也可能是书眉；不要求它与其他页完全同文。附近不重叠页码带的图注要保留。
3. 真实段落与纸页分开：下一页首列没有段首缩进且原文是接续句时，将前页最后段与后页接续段
   作为一个语义单元翻译。例如“文／学”是跨页词语，不能逐页翻成两个独立段落。当前自动页级翻译只提供邻页上下文；组级联译属于阅读稿修复，不能作为正式页级检查点。
   普通断行用段落重建；跨页联译必须记录 `source_pages`、源 SHA 和输出文本，不能删除后页源记录。
4. 使用 DeepSeek Flash 输出完整中文段落；日语译中文时保留源文全部标点字形、顺序和数量。语言残留先于符号检查；引用、书名也要译。
   每单元至多首轮＋一次修复。被拒绝的输出保存到审计目录，不直接用于读者成品。
   暂译名、无法恢复的缺损显式记录；不得以删字符或新增省略号掩盖识别问题。
5. 检查实际章节、Word 段落、EPUB 与语料，而非只看“成功”检查点。
   `reader_layout_issues` 按本章源页范围查原页边副本及连续碎片，避免把另一页的页码值误当正文编号。
   原书页眉页脚不进入正文；真实章标题/正文编号保留，读者版自身的排版页码属于版式。
6. 用 Word 实际渲染检查反馈位置和修复处。报告注明实际看的页号、代理/人类身份、范围；
   语言/版面通过不能证明源图逐字正确。新联译稿的引文符号须独立比较，不能沿用旧检查点的通过数。

当前 `compile_chapters(reader_page_groups=...)` 支持可追溯的联译阅读草稿；该参数不能绕过正式
逐页翻译验证。完整正式发布仍按源图、人类记录和当前机器报告决定。

联译组本身也要纳入引文符号验收：用组内 source_pages 的正文顺序拼出源签名，再与这组实际译文比较。
原有逐页检查点的“通过”与新组译文无关。遇到符号不一致时保留差异和页号，不机械回填原符号，
也不把这批中文草稿记作已验收的正式译文。

## 替换用户认可的阅读版

- 确认要替换的原工作区及当前使用的文件名；同一本书多个旧交付目录须避免旧文件继续被误用。
- 备份旧工作区或所有将替换的文件、审计和旁车，记录原文件 SHA。新版在独立目录先验证。
- 用新版章节重新导出 Word/EPUB 与规范五字段语料。保留原始 OCR，更新质检报告和替换清单。
- 语料内容变了，旧向量、embedding cache、apparatus 与 RAG manifest 不可继续声称有效。
  用原有索引接口重建；仅更新相关书。不能以 lexical 静默降级冒充 hybrid 可用。
- 旧“已验证/已注册”回执绑定旧文件哈希；保存在备份，当前回执失效后须重新验证。
  用户认可新版阅读效果是采用/替换授权，不等于确认每一页原文匹配；保留未通过项。
- 若新版质检报告的 `release_ready` 为 false，替换的只是当前阅读草稿：目标目录必须移除旧版规范
  `knowledge_base.jsonl`、向量、embedding cache、RAG/apparatus 旁车及旧发布/注册回执；不能让旧索引
  混入新 Word/EPUB，也不能注册新稿。机器语言通过不代表 OCR、引文符号或语义已核图。
- 仅在当前新版通过完整发布验收后，才把新 Word/EPUB/书签 PDF 与五字段正式语料放进活动目录，
  随后重建该书向量并绑定新文件摘要。旧版本完整留在已注明版本和日期的备份目录中。
- 文件被 Word 占用时，不关无关文档或丢弃用户编辑。保存相关编辑副本，或提供清楚标记的待替换文件，
  不把未成功覆盖说成已完成。替换后逐文件校验、实际核读已报告位置，并交付 `audit/quality-report.md`。

## 个案经验的边界

《江藤淳与少女女性主义的战后》的“二／三／工”来自日文书眉碎片，不是作者正文。
PDF66—69 的“サブカルチャーの／側から”和“文／学”须连页理解。其他书不能照抄这些页号、
片段删除规则或暂译名；复用的是定位、几何分离、语义联译和真实产物质检的方法。
