# 字段与验收门

## 字段去向

| 层 | 必留 | 不得混入 |
| --- | --- | --- |
| pages/*.json | 英文原文、中文译文、模型/来源身份、块坐标与原页号 | 不修改为读者版文字 |
| 选文 Markdown | 中文篇名、原书正文段落、可核定的正文引注 | 编者导言、运行页眉、PDF 页码、模型解释 |
| 知识库 JSONL | id、title、chapter_id、chapter_order、content 五字段 | 额外元数据字段、脚注定义、未审定编者评论 |
| audit/*.json | 目录角色、裁切文本、脚注候选、段落证据、报告与回执 | 宣称未实际执行的源图或视觉审阅 |
| Word/EPUB | 与当前 Markdown 同序、同文、标题与真脚注 | 乱码、跨栏串行、重复页脚、来源处理标记 |
| RAG 旁车 | 绑定当前语料摘要的词法/向量状态 | 旧语料的向量或错误“已就绪”状态 |

保存原文页和译文页并不足以证明选文完整。抽查目录项起止页、两栏、密集注释页和
跨页句，核对选文首尾没有编者材料，也没有丢掉作者正文。目录中的同名作者与
跨部编重复条目以 TOC ID 和篇名识别。

## 脚注与清洗

- 依原页底部区域、字体和注号确认作者注、编者注、译者注；Markdown [^id] 正文
  引用和定义须双向一一闭合。仅靠数字、距离或标签数量不能确定附着位置。
- 出现 [Ed.] 与 [Au.] 相邻、脚注与正文同页交错、印刷页号误入句中时，先保留
  原始检查点，再写有精确源页和译文片段的审定稿。任何“整行删除”必须指出它是
  页眉、脚注还是噪声，不能把引文数字、年份、正文节号一起删掉。
- 希腊文、拉丁文和英文引用按用户要求译入中文；人名、作品名、原文出处和合法
  引文编号可保留在注释或出处字段。中文语言门不能靠删掉作者原话来通过。
- 后端生成 editorial-note-census.json，标出英文 [Ed.] 与中文编者标记的差异；
  editorial-note-reader-gate.json 记录规范语料剩余标记数。人工解释差异要绑定页号，
  不能把不确定注释随意贴到最近句子。

## 分层验收

1. extract/ocr：源 PDF 摘要、页数、所需页检查点、文字层与源图读序；低文字页
   不自动判为空白。
2. plan/draft：TOC 每项角色、中文选文标题、共享页裁切或逐章审定；章节门和
   五字段正文库；段落、脚注异常先在源级修。
3. publish/verify：同一候选的 Word、EPUB、参考 PDF 和知识库；完整报告要求
   status=passed、release_ready=true、failed=0、skipped=0。Word 的正文、
   真脚注 OOXML、渲染页和中文语言门分别通过；PDF 外观、文字层、页数和书签
   与源件对应。出版目录中仅有成品文件并不等于验收完成。
4. register：视觉记录绑定当前 DOCX；语料已过中文门，RAG 清单与向量校验和
   绑定当前知识库。off/auto/on 模式及提供者配额结果如实返回。旧回执或旧向量
   不能替代新版本的检索验证。

把章节审定与章节门用于高频返工；内容稳定后只做一次完整 Word/PDF 构建和发行门。
完整报告失败时只重做受影响阶段及其下游，避免反复 OCR 已验证的页。状态摘要
必须用本次报告的实际数字，不能沿用前一本书的篇数、脚注数或书签数。
