选择一条输入路径

悬停或点击节点查看输入、产物和是否缓存。虚线表示每次进入节点，由页级检查点或验收器决定实际工作量。

一次运行如何恢复

Graph 负责节点依赖和产物指纹，耗时阶段另有自己的检查点。相同输入重跑时跳过完成工作；源内容、模型、提示词或配置变化会让对应缓存失效。

发布档位与阻断项

草稿目标可以直接生成文件。正式报告只有在全部必需检查通过后才是 release_ready。样书暴露了竖排 OCR 的真实质量边界。

已经落地的性能修复

优化保留原有正确性边界：永久请求错误不再拆批，缓存仍重新校验内容，知识库更新失败不会替换旧库。

更新生产会话

开发成果不直接进入生产目录。单一集成人串行审查、合并并完成版本回归后，才更新生产会话；这一步同时完成代码同步和上下文交接。
